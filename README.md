# 바우처 서비스 추천 화면 (과제 목업)

EC21R&C 기획 직무 과제 「수출바우처 서비스 추천」 기획안의 6-6 화면입니다.
참가신청서 정보로 서비스 유형을 추천하고, 유형 안에서 메뉴판 서비스를 정렬해 보여주는 카드형 결과 화면입니다.

## 구성

```
index.html                     화면 구조
assets/css/style.css           스타일 (기준 폭 1440px, 1024px 이하 1단)
assets/js/app.js               추천 계산(기획안 6-2, 6-3)과 화면 갱신
assets/js/data.js              과제 자료와 기획안 규칙 (출처는 DATA._source)
assets/fonts/PretendardVariable.woff2   Pretendard (SIL Open Font License 1.1)
```

## 데이터 원칙

- 기업은 과제 자료 D-1의 가상 기업 60개, 서비스는 자료 B-2 메뉴판 샘플 300건만 사용합니다.
- 국가별 강제 인증표(R1), FTA 체결국(R2), 비영어권 국가, 단계 핵심 유형은 기획안에 "가정"으로 적은 참조 정보입니다.
- 서비스의 국가, 품목 태그는 서비스명과 소개글에서 1차로 추출한 값이며 검수 전입니다.
- 자료 D에 없는 신청서 항목(13, 15, 16, 22, 23번)은 비워 두고, 화면에서 시연용으로 입력할 수 있게 했습니다.
- 추천 이유 문장은 판정에 쓴 값으로 만든 템플릿입니다. 실제 서비스에서는 AI가 근거 값만으로 문장을 만들고 검증합니다(기획안 6-5).
